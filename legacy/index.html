Legacy

CubeOS Legacy

Терминальная операционная система

Минималистичная версия CubeOS — только терминал в VESA-графике. Быстрая загрузка, низкое потребление памяти, полный набор команд.

Скачать ISO (Legacy) Инструкция по запуску

Системные требования

Минимальные

ОЗУ 5 MB
Процессор x86_64 ~50 MHz
Графика VESA 800×600
Диск Не требуется
Рекомендуется

Рекомендуемые

ОЗУ 32 MB
Процессор x86_64 100+ MHz
Графика VESA 1024×768
Диск ATA с FAT32

Возможности

Терминал в VESA

Полноценный терминал в графическом режиме. Цветовые темы.

FAT32 с полной поддержкой

Чтение и запись файлов, создание и удаление папок, навигация по директориям.

ACPI Shutdown

Корректное выключение компьютера через ACPI.

104-клавишная клавиатура

Поддержка всех стандартных клавиш. Shift для заглавных букв. NumPad.
