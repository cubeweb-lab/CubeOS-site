# Документация CubeOS

CubeOS — 64-битная операционная система, написанная на языке Rust.  
Проект создаётся для изучения низкоуровневого программирования и архитектуры ОС.

## Версии системы

### CubeOS (Main)
Основная ветка с графическим интерфейсом.

**Возможности:**
- Оконный менеджер (перетаскивание, сворачивание, закрытие)
- Панель задач и меню «Пуск»
- Обои рабочего стола (BMP, сплошные цвета)
- Темы оформления (Warm, Classic, Cool, Vista)
- Графический файловый менеджер
- Встроенный терминал с цветовыми темами
- Окно настроек (Display, Appearance, About)
- Калькулятор

**Минимальные требования:**
- ОЗУ: 19 MB
- Процессор: x86_64, ~100 MHz
- Графика: VESA 800×600×32

### CubeOS Legacy
Терминальная версия в VESA-режиме.

**Возможности:**
- Полноценный терминал с историей команд
- Поддержка FAT32 (чтение, запись, создание, удаление)
- Цветовые темы (Classic, Matrix, Mint, Peach, Surprise и другие)
- ACPI shutdown
- 104-клавишная клавиатура с Shift

**Минимальные требования:**
- ОЗУ: ~8 MB
- Процессор: x86_64, ~50 MHz
- Графика: VESA 800×600×32

## Как запустить

### Требования
- QEMU 6.0 или новее
- Образ диска FAT32 (опционально, для работы с файлами)

### Запуск CubeOS (Main)
```bash
qemu-system-x86_64 -cdrom cubeos.iso -m 1024M -vga vmware -no-reboot -no-shutdown
```

С образом диска:
```bash
qemu-system-x86_64 -cdrom cubeos.iso -hda fat32.img -m 1024M -vga vmware -no-reboot -no-shutdown -boot d
```

### Запуск CubeOS Legacy
```bash
qemu-system-x86_64 -cdrom cubeos-legacy.iso -m 1024M -no-reboot -no-shutdown
```

С образом диска:
```bash
qemu-system-x86_64 -cdrom cubeos-legacy.iso -drive file=fat32.img,format=raw,cache=unsafe -m 1024M -no-reboot -no-shutdown -boot d
```

### Создание образа FAT32
```bash
dd if=/dev/zero of=fat32.img bs=1M count=64
mkfs.fat -F 32 fat32.img
```

## Сборка из исходников

> **Примечание:** исходный код на данный момент закрыт.  
> Инструкция будет доступна после открытия репозитория.

### Требования для сборки
- Rust nightly
- NASM
- GCC (для компиляции C-файлов)
- ld.lld (линкер)
- grub-mkrescue (для создания ISO)
- mtools (для работы с FAT-образами)

### Сборка
```bash
git clone https://github.com/cubeweb-lab/cubeos.git
cd cubeos
make setup
make
```

### Запуск
```bash
make run
```

## Архитектура

### Загрузка
1. GRUB загружает ядро (multiboot2)
2. `boot.asm` настраивает Long Mode, страничную адресацию, GDT, TSS
3. Переход в `rust_main`

### Ядро (CubeOS Main)
- **Графика:** VESA-фреймбуфер через multiboot2
- **Окна:** собственный оконный менеджер
- **Память:** прямая работа с фреймбуфером, двойная буферизация
- **Прерывания:** IDT, обработчики исключений, BSOD/GSOD
- **Устройства:** PS/2 мышь, клавиатура, ATA

### Ядро (CubeOS Legacy)
- **Терминал:** прямой вывод в VESA-фреймбуфер
- **Буфер:** кольцевой буфер клавиатуры
- **ATA:** PIO-режим, спинлок для защиты портов
- **ACPI:** shutdown через порт 0x604

### Файловая система
- **Тип:** FAT32
- **Драйвер:** собственный, на Rust
- **Поддержка:** чтение/запись, создание/удаление файлов и папок
- **Особенности:** работает с RAM-диском и реальным ATA

## Команды терминала

### Общие команды
| Команда | Описание |
|---------|----------|
| `help` | Показать список команд |
| `ver` | Версия системы |
| `mem` | Информация о памяти |
| `uptime` | Время работы (в тиках) |
| `cls` / `clear` | Очистить экран |
| `dice` | Бросить кубик |
| `about` | О системе |
| `cubefetch` | Информация о системе (как neofetch) |

### Файловые команды (при наличии диска)
| Команда | Описание |
|---------|----------|
| `dir` | Список файлов и папок |
| `cd <папка>` | Перейти в папку |
| `read <файл>` | Прочитать содержимое файла |
| `write <файл>` | Записать текст в файл |
| `mkdir <имя>` | Создать папку |
| `del <файл>` | Удалить файл |

### Системные команды
| Команда | Описание |
|---------|----------|
| `theme <имя>` | Сменить тему терминала |
| `shutdown` | Выключить компьютер (ACPI, только Legacy) |
| `crash <0-31>` | Вызвать исключение (для тестирования BSOD) |

## Файловая система

CubeOS использует FAT32 как основную файловую систему.

### Поддерживаемые операции
- Чтение файлов
- Запись в файлы (размер ограничен одним кластером)
- Создание файлов и папок
- Удаление файлов
- Навигация по директориям

### Ограничения
- Длинные имена файлов (LFN) не поддерживаются
- Размер файла ограничен размером кластера (обычно 512-4096 байт)
- Фрагментация не обрабатывается
- Только FAT32, без поддержки FAT16/FAT12/exFAT

### Кэширование записи
При использовании QEMU с `-hda fat32.img` изменения могут не сохраняться на диск из-за кэширования QEMU. Используйте `-drive file=fat32.img,format=raw,cache=unsafe` для немедленной записи.

## Известные проблемы

### CubeOS (Main)
- ATA-драйвер может вызывать Triple Fault при инициализации на некоторых конфигурациях
- Прерывания мыши требуют ремапа PIC
- Иногда наблюдается утечка стека при длительной работе GUI
- Шрифт Tamzen 8×16 не поддерживает кириллицу

### CubeOS Legacy
- Нет поддержки LFN (длинных имён файлов)
- Нет поддержки мыши
- ACPI shutdown работает только в QEMU (порт 0x604)
- Команда `write` записывает только тестовую строку

### Общие
- Нет поддержки сети
- Нет звука
- Только x86_64 архитектура
- Нет поддержки USB
- Нет многозадачности (только кооперативная)
